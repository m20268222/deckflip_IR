# 같은 장소에서 여러 기기로 투표하기

이 서버는 발표자 컴퓨터에 표와 질문을 함께 모읍니다. 같은 서버 주소와 같은 `poll` 값을 사용하는 기기끼리 결과를 공유합니다. 각 기기에서만 숫자가 바뀌는 로컬 데모와는 다릅니다.

Node.js 20 이상이 필요합니다. 추가 패키지 설치는 없습니다. 이 폴더에 있는 `index.html`, `deck.html`, `vendor`와 함께 사용합니다. 두 페이지는 `poll-config.js` 설정을 읽도록 준비되어 있어야 합니다.

## 이 컴퓨터에서 확인

이 폴더에서 PowerShell을 열고 다음 명령을 입력합니다.

```powershell
node .\tools\local-poll-server.mjs
```

표시된 `Audience`와 `Presenter`는 **같은 `index.html?poll=회차값#voice` 주소**입니다. 이 주소를 청중 휴대폰과 발표자 컴퓨터에서 함께 열어야 같은 질문과 집계를 봅니다. 기본 주소는 `http://127.0.0.1:8749/`이며 다른 컴퓨터나 휴대폰에서는 이 주소로 접속할 수 없습니다.

`기존 IR 덱(별도 질문)` 링크는 내용과 투표함이 다른 과거 발표 자료입니다. 현재 참여자 화면의 발표용 집계 화면이 아닙니다. 서버는 혼선을 줄이려고 이 링크에 별도의 `-legacy` 회차값을 붙입니다.

## 같은 와이파이의 휴대폰에서 참여

```powershell
node .\tools\local-poll-server.mjs --lan
```

1. 발표자 컴퓨터와 휴대폰을 같은 와이파이에 연결합니다.
2. 출력된 주소 중 `127.0.0.1`이 아닌 컴퓨터의 내부망 주소를 사용합니다. VPN 등으로 주소가 여러 개면 실제 와이파이 주소를 고릅니다.
3. 같은 내부망 주소의 `Presenter` 링크를 컴퓨터에서 열고 `Audience` 링크를 휴대폰에서 엽니다. 두 링크의 `index.html`, `poll` 값, `#voice`가 모두 같은지 확인합니다. 발표 화면의 QR도 이 주소를 가리키는지 확인합니다.
4. 실제 휴대폰에서 한 표를 보내 발표 화면에 반영되는지 확인합니다. 쇼케이스에는 투표 두 문항이 있고, 자유 질문은 별도로 안내한 기존 덱에서만 사용합니다.

휴대폰의 `localhost`나 `127.0.0.1`은 휴대폰 자신을 뜻합니다. 공유한 기기가 모바일 데이터로 전환되면 내부망 서버에 접속할 수 없습니다. 공개 GitHub 주소도 이 서버로 자동 연결되지 않습니다.

Windows 방화벽 또는 행사장 와이파이의 기기 간 통신 차단 때문에 접속이 안 될 수 있습니다. 이 프로그램은 방화벽 설정을 바꾸지 않습니다. 행사 전 실제 장소에서 연결을 확인해야 합니다. 서버를 켠 컴퓨터의 절전 모드·전원 종료·네트워크 변경도 집계를 중단시킵니다.

## 종료와 기록

서버를 켠 터미널에서 `Ctrl+C`를 누르면 종료됩니다. **표와 질문은 메모리에만 저장되므로 종료·재시작·컴퓨터 종료 시 모두 사라집니다. 파일 저장과 자동 복구 기능은 없습니다.** 서버를 켜 둔 동안에는 페이지를 새로 열거나 다른 기기에서 접속해도 같은 집계를 볼 수 있습니다.

실행할 때마다 새로운 `poll` 값이 붙은 링크를 출력합니다. 재시작 후에는 새 링크를 사용하십시오. 이전 링크를 다시 쓰면 브라우저에 남은 “이미 투표함” 표시와 비어 있는 서버 집계가 맞지 않을 수 있습니다.

필요하면 종료 전에 다음 명령으로 해당 회차의 자료를 직접 저장할 수 있습니다. 주소와 `local-회차값`은 실제 사용한 값으로 바꾸십시오.

```powershell
Invoke-RestMethod 'http://127.0.0.1:8749/poll-api/rest/v1/deck_votes?select=*&poll=eq.local-회차값-q1&limit=4000' | ConvertTo-Json -Depth 5 | Set-Content -Encoding UTF8 '.\votes.json'
Invoke-RestMethod 'http://127.0.0.1:8749/poll-api/rest/v1/deck_questions?select=*&poll=eq.local-회차값-legacy&order=created_at.desc&limit=4000' | ConvertTo-Json -Depth 5 | Set-Content -Encoding UTF8 '.\questions.json'
```

이 명령은 응답 최대 4,000건을 저장합니다. 자동 백업 기능이 아니므로 중요한 기록은 종료 전에 파일 내용을 확인하십시오. 페이지별 질문의 `poll` 값이 별도로 나뉘는 경우 각 값을 조회해야 합니다.

## 적용 범위

- 서버 접속은 기본적으로 이 컴퓨터에 한정됩니다. `--lan`을 명시해야 모든 IPv4 인터페이스에서 접속을 받습니다.
- 같은 내부망에서 주소를 아는 사람은 투표·질문을 보내고 결과를 읽을 수 있습니다. 로그인·참가자 신원 확인·서버 측 1인 1표 보장은 없습니다. 익명 현장 참여용이며 민감한 질문을 수집하지 마십시오.
- 인터넷 공개 서버 대체물이 아닙니다. 외부 공개나 포트 포워딩을 전제로 만들지 않았습니다.
- 외부 출처의 쓰기 요청을 거부하며, JSON 요청은 4KB 이하입니다. 기기 IP당 쓰기 60회/분, 집계 조회 300회/분을 넘으면 잠시 제한합니다.
- `poll` 값은 영문·숫자·밑줄·하이픈 1~80자, 선택지는 숫자 `0` 또는 `1`, 질문은 1~100자입니다. 각 테이블은 서버 기동당 최대 20,000건입니다.
- 로컬 응답은 외부 서버로의 데이터 연결을 차단합니다. 기존 Supabase 계정·테이블·데이터에는 접속하지 않습니다.

다른 포트를 쓰려면 `--port 8750`을 추가합니다. 명령 도움말은 `--help`입니다.

```powershell
node --test .\tests\local-poll-server.test.mjs
```

위 검사는 임시 로컬 서버만 사용하며 실제 Supabase에는 접속하지 않습니다.
